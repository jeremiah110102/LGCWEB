Text, colors, media, announcements, page structure, history, and exports are stored in the files inside this LGC project folder.

What gets saved?Text and layouts → data/pages · Colors → data/section-colors.json and public/css/section-colors.css · News → public/data/news.json · Media → public/assets/uploads.

Structured editor

Edit page content

Use the page and section filters to update headings, descriptions, labels, calls-to-action, and links without opening HTML.

Replace photos or video files

Choose the page containing the current image or video, then upload its replacement. The new file stays inside this local website folder.

Upload allowance: up to 1 GB per file by default. Large files stay local. For smoother loading, use a web-optimized MP4 and keep individual photos below 30 MB when possible.
